# Bounded collaboration handoff

Post in the relevant working thread; link a durable GitHub task/PR when applicable. Use only inputs allowed by the recipient's review/experiment boundaries.

**From:** model, role, task/session  
**To:** named counterpart, role, task/session  
**Type:** proposal / question / advisory review / authorized work / outcome  
**Request:** one bounded action or decision, with rationale  
**Authority:** verifiable owner instruction and allowed scope; otherwise explicitly proposal only  
**Target:** repository, task/PR, base SHA and head SHA (where relevant)  
**Evidence:** links; checks run/read; results and verification gaps  
**Independence:** fresh blind / informed follow-up / not applicable; context already seen  
**Ownership:** current active task; whether this hands it off or only requests input  
**Limits:** local safeguards, budget, approval gates and excluded work  
**Receipt:** intended session acknowledgement or verifiable action expected by the agreed checkpoint  
**Fallback:** agreed route if delivery/access/receipt fails  
**Completion:** what closes this handoff
